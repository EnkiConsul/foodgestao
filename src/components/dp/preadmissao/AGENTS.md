# Pré-Admissões
- Keep the list mobile-first with non-scrolling stage filters; reuse existing server mutations and the official review form to preserve admission validation.
- Invite tokens are shown only on creation; never infer an existing invite URL. Regenerating a link requires explicit confirmation because it invalidates the previous link.
- WhatsApp dispatch uses explicit Android package intents with HTTPS fallback; elsewhere offer system sharing without claiming app selection is guaranteed.- Pre-admission OCR (`ler_documento` in `dp-preadmissao-arquivo`, fields in `_shared/preadmissao-ocr.ts`) only suggests values for empty fields; never writes, never overrides name/CPF — server validation on save stays the source of truth.
- The candidate's 3x4 photo/selfie is always mandatory (checklist ignores company rules for it) and, on completion, is linked to the company's `foto_cadastro` requirement so it becomes the employee profile photo.
- OCR divergences (name/CPF/birth date) are logged as `ocr_divergencia` events and only warn; they never block the candidate.
- Manager review is guided tab by tab (`ABAS_CONFERENCIA`); the final save completes review only after every tab was opened and OCR divergences are resolved. Navigation waits for form persistence; ASO and accounting remain separate resumable steps. The PDF is never blocked: before approval/ASO it downloads as a watermarked preview.
- Admission exam (ASO) lives in `admin_dados.aso`, written only by `salvar_aso` (gestor fn) and `aso_arquivo` (arquivo fn); dispensation requires owner/admin, legal basis, ≥15-char justification and acknowledgment. `enviado_contabilidade` is refused server-side without an Apto ASO file or a formal dispensation.
- Document nature follows the vínculo via `documentoPorVinculo` (`src/lib/dp/vinculo-documento.ts`, mirrored in `_shared/vinculo-documento.ts`): PJ/MEI → "Cadastro de Prestador PJ", freelancer → "Ficha de Profissional Eventual", estágio/temporário own titles; ASO and the accounting gate apply only to CLT/intermitente (`regimeEhEmprego`), enforced server-side in `salvar_aso` and `marcar_status`.
- Documents of two sides (`exigeVerso` in `src/lib/dp/documentoPartes.ts`) need front+back unless a single PDF or a part labeled "Frente e verso"; the candidate cannot send the form with a back missing, and the manager may attach/replace/reframe via `upload_gestor` (new version, previous kept, event `documento_ajustado_gestor`). Files open only in the in-app `ArquivoVisualizadorDialog`; download is explicit.
- Selfie 3x4 always passes through `ImagemEnquadrarDialog` (oval badge mask) for candidate and manager.
- Employment regimes (CLT/intermitente) in a unit with a time clock get `possui_folha_ponto = true` by trigger `trg_dp_colab_ponto_clt_padrao`, unless a dispensation justification exists.
- Manager re-read (`ler_documento_gestor`) follows the same OCR rule: fills only empty form fields, never name/CPF, never saves by itself.
- Pré-admissão: o checklist compartilhado governa leitura e envio; desativar requisito preserva anexos.
- Pre-admission correction/retake uses a service-only atomic RPC with expected version and actor audit; retake is explicit, never triggered by an upload, and never bypasses admission checks. Renew the existing non-revoked invite without shortening its expiry or exposing/regenerating its token; WhatsApp refers to the previously received link.
- Pre-admission activation inherits the reviewed habitual sector into the employee and empty worked-day slots, preserving explicit daily sectors and validating company scope.
- Pre-admission document groups use requirement plus person identity and retain individual versioned decisions; portrait panning protects the face guide while document cropping protects all edges, using the shared geometry helper.
- Efetivação direta da pré-admissão: `dp_preadmissao_efetivar_direto` cria o colaborador a partir dos dados conferidos (sem ficha de registro); vínculo CLT/intermitente exige confirmação expressa registrada em evento, demais vínculos dispensam a ficha — a ficha oficial é opcional, nunca bloqueio.
- Ficha do candidato por vínculo: `padraoPorVinculo` (`_shared/preadmissao.ts`) dispensa CTPS/PIS/título/reservista fora de CLT; regras da empresa sempre prevalecem.
